# dkstuff

**A collection of small projects, experiments, and random ideas.**

Welcome to **dkstuff**, a place where I put things I build for fun, curiosity, or simply because I felt like writing some code.

Nothing here is meant to be particularly professional or production-ready. Some projects are useful, others are just experiments, and a few probably exist for no good reason at all.

### What's in here?

- **Small utilities** • Tools that solve tiny problems.
- **Experiments** • Trying out languages, libraries, and random concepts.
- **Weekend projects** • Ideas that turned into code.
- **Random stuff** • Things that don't really fit anywhere else.

### A few things to keep in mind

Projects here might be unfinished, unmaintained, poorly documented, or occasionally broken.

That's kind of the point.

This is a playground, not a product catalog.
